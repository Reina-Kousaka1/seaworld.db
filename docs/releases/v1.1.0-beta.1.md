# SeaWorld DB v1.1.0-beta.1

`v1.1.0-beta.1` is a pre-release of the embedded Rust engine. It advances the
package version while retaining Public API `1.0.0`, current on-disk format V4,
V1--V4 read compatibility, and the Java-generated V1 fixture.

## Added since v1.0.0

- Transaction snapshot-version visibility and staged atomic numeric
  increment/decrement mutations.
- Native `Transaction::compare_and_set`, evaluated against the transaction's
  staged view and persisted through the existing atomic transaction/recovery
  path.
- Opt-in, non-persistent optimization diagnostics for reads, writes, scans,
  index access, compare-and-set attempts, and bounded document observations.
- Explainable index, hot-document, and CAS-contention recommendations.
- Bounded workload profiles, evidence-bearing optimization candidates,
  qualitative benefit/cost/confidence, and read-only simulations.
- Explicit preceding/current observation windows, deterministic count-backed
  workload-drift detection, and candidate/simulation re-evaluation that marks
  no-longer-representative evidence stale or invalidated.

## Compatibility and boundaries

- Public API remains `1.0.0`; the new diagnostic APIs are native extensions,
  not `PublicEngine` capabilities.
- No new on-disk format, migration, dependency, or `unsafe` code was added.
- The engine remains single-writer. There is no multi-writer conflict protocol,
  serializable isolation, durable request idempotency, automatic optimization,
  automatic index creation, storage-plan application, migration, cluster,
  replication, sharding, or distributed transaction support.
- Diagnostic observation, simulation, drift, and lifecycle state are opt-in,
  bounded, handle-local, non-persistent, and cannot alter database bytes,
  indexes, query plans, transactions, or locks.

See the [full beta scope and qualification criteria](../v1.1.0-beta.1-scope.md)
for the version-space policy and release gate.
