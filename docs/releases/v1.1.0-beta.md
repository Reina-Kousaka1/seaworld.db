# SeaWorld DB 1.1 Beta

SeaWorld DB 1.1 Beta is a pre-release of the embedded Rust engine. The Cargo
package version is `1.1.0-beta`, published under tag `v1.1.0-beta`. This
release keeps Public API `1.0.0`, the V4 on-disk format, V1--V4 read
compatibility, and the Java-generated V1 compatibility fixture.

## Changes since v1.1.0-beta.1

- **V4 compaction preserves the source format.** Compaction of a V4 database
  now produces a V4 copy, rebuilds live persistent index roots, and preserves
  index behavior. A regression that produced a V3 copy from a V4 source is
  covered by a regression test.
- **Backup and compaction crash qualification is broader.** The process-kill
  harness covers temporary-copy creation, copy transactions, pre-publication,
  post-hard-link publication before directory sync, and post-directory-sync
  before temporary-file cleanup. Before publication the target is absent;
  after publication an interrupted operation may leave only a complete,
  validated copy. Directory-sync failures after publication can still leave a
  complete target whose final durability is uncertain.
- **V1 tail recovery is qualified across sync boundaries.** Tests interrupt
  recovery after truncation but before sync and after sync, then check that the
  next open is coherent and idempotent. Complete checksum or semantic
  corruption continues to fail closed rather than being skipped.
- **Core and durability invariants are documented.** The commit acknowledgement
  boundary is the successful file sync before in-memory publication. The
  recovery decision is the complete transaction commit marker. Process-kill
  coverage does not claim power-loss survival.
- The Rust 1.89 MSRV is explicitly qualified by CI, and the security and
  platform documentation now states the supported boundaries.

Transaction compare-and-set, staged numeric mutations, opt-in optimization
diagnostics, workload profiles, recommendations, drift detection, and
recommendation lifecycle were already present in v1.1.0-beta.1. They remain in
this release; this release adds no new optimizer or compare-and-set behavior.
Their existing transaction and recovery tests remain part of the complete CI
suite.

## Compatibility and release qualification

- Public API: `1.0.0`; on-disk format: V4; readable formats: V1--V4.
- The Java-generated V1 fixture remains supported.
- No new dependencies or `unsafe` code were added.
- The release commit passes the repository's GitHub Actions matrix: 126 tests
  on Ubuntu and 126 on Windows, Rust 1.89 MSRV, formatting, diff check, both
  Clippy modes, the process crash harness, and the release build.

## Boundaries

SeaWorld remains a single-writer embedded engine. This release does not provide
Serializable transactions, multi-writer MVCC, automatic conflict retries,
durable request-ID idempotency, clusters, replication, Raft, ARM64/Raspberry
Pi qualification, WiredTiger integration, or automatic storage optimization.

Process-crash tests and successful file syncs do not establish universal
power-loss durability. CRC32C detects accidental corruption; it is not
authentication. The documented filesystem, OS, device, resource-limit, and
platform boundaries still apply.
