MEASURE, THEN COMPARE

No made-up
throughput charts.

The repository contains a rigorous test and crash-qualification story, but no checked-in reproducible performance benchmark result suitable for publication on this site. Accordingly, there are no fabricated latency or operations-per-second claims here.

Methodology

Record hardware, OS/filesystem, Rust version, database format, dataset shape, transaction size, index layout, warm-up, repetitions and percentile calculation. Publish raw command lines and data alongside results.

Correctness first

Use the repository’s engine, process-crash, generated and differential tests before comparing workloads. A faster result without the documented recovery checks is not a SeaWorld qualification result.
